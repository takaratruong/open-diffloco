# G1 Raw-Reference AHAC Walking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a provenance-bound AHAC optimizer treatment for the unchanged E023 G1 walking task and run one matched seed-zero comparison.

**Architecture:** Keep the existing SHAC rollout and experiment machinery, isolate AHAC math in a small pure module, and add only narrow integration seams for a masked adaptive horizon, double critic, convergence-controlled critic fitting, resume metadata, and telemetry. Calibrate contact stiffness mechanically from the frozen E023 policy before the fresh treatment run.

**Tech Stack:** Python, JAX/MJX, Flax, Optax, pytest, Ruff, DiffSim2Real experiment registry.

## Global Constraints

- Preserve the raw walking reference; no collocation or dynamic retargeting.
- Preserve E023's plant, observations, rewards, actor, action-noise schedule, CAGrad, effective population, seed, and 128 actor updates.
- AHAC horizon is bounded to 8--24; dual learning rate is exactly `5e-4`.
- Contact threshold is the deterministic E023 five-phase 90th percentile, never selected from treatment performance.
- Double critic fitting stops at convergence or 64 iterations.
- No threshold, horizon, learning-rate, reward, or seed sweep.
